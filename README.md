# Real-Time Chat Application

A full-stack real-time chat application built with React, Express, Socket.io, and MongoDB.

## Features

- JWT authentication
- One-to-one messaging
- Real-time messages
- Online/offline presence
- Typing indicator
- Read receipts
- Message history
- Responsive interface

## Tech Stack

- React.js
- Node.js
- Express.js
- Socket.io
- MongoDB
