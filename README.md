# Real-Time Chat Application

A full-stack real-time chat application built using React.js, Node.js, Express.js, MongoDB and Socket.io.

## Features

- User authentication
- One-to-one messaging
- Real-time communication
- Online/offline status
- Read receipts
- Conversation management
- MongoDB database

## Tech Stack

- React.js
- Node.js
- Express.js
- Socket.io
- MongoDB
